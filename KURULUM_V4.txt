KİTAP TAKİP PREMIUM V4 — YAZI VE GÖRÜNÜM PAKETİ

Bu paket, mevcut çalışan projenin tamamıdır.

KURULUM
1. ZIP'i ayrı klasöre çıkarın.
2. VS Code ile bu yeni klasörü açın.
3. Terminal:
   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install -r requirements.txt
   python manage.py migrate
   python manage.py runserver
4. Tarayıcıda Ctrl + F5 yapın.

DÜZELTİLENLER
- Etüt hocası panelindeki bütün sayfaların ortak tipografisi
- Talebeler, kitaplar, zimmet, günlük okuma, sınav ve raporlar
- Özel yönetim paneli başlıkları, menüleri, kartları ve listeleri
- Küçük ve silik yazılar
- Form alanları ve düz tarayıcı butonları
- Kart sınırları ve kontrast
- Hoş geldiniz başlığında sofistike kıvrımlı stil

QIMANO NOTU
Qimano bilgisayarda kuruluysa tarayıcı otomatik kullanır. Kurulu değilse güvenli yedek fontlar devreye girer.
