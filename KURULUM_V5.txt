KİTAP TAKİP PREMIUM V5

Bu paket V4 projesinin tamamıdır. Eski projeye dönmeniz gerekmez.

1. ZIP'i çıkartın.
2. Çıkardığınız klasörü VS Code ile açın.
3. Terminal:
   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install -r requirements.txt
   python manage.py migrate
   python manage.py runserver
4. Tarayıcıda Ctrl + F5 yapın.

Not: Poppins ve Great Vibes Google Fonts üzerinden yüklenir. İnternet yoksa güvenli yedek fontlar kullanılır.
