KİTAP TAKİP PREMIUM V6

1) ZIP'i ayrı klasöre çıkarın.
2) VS Code ile, manage.py ve requirements.txt dosyalarının göründüğü klasörü açın.
3) Terminal:
   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install -r requirements.txt
   python manage.py migrate
   python manage.py runserver
4) Tarayıcıda Ctrl + F5 yapın.

V6 ana yenilikler:
- Hareketli/desenli üst menü
- Admin dashboard: grafik yerine hızlı işlemler, sınıf geçişleri, günlük durum ve aktif kitaplar
- Renkli/zengin talebe kartları
- Zimmet ekranında seçilen kitabın toplam sayfa sayısı
- Tarih/sınıf/durum filtreli okuma raporları ve ReportLab PDF
- Üst menülü özel yönetim merkezi
- Animasyonlu kitap silüetli giriş ekranı
